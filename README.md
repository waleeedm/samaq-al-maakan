# Samaq Al Maakan — Standalone GitHub Pages Website

This is an independent, bilingual English/Arabic static website. It does not require EGCAN, another repository, or another website to be published.

## Files to upload
- `index.html` — website page
- `styles.css` — layout and design
- `script.js` — language switch, mobile menu and enquiry form behavior
- `.nojekyll` — GitHub Pages support

## Publish as its own website
1. On GitHub, click **New repository**.
2. Name it `samaq-al-maakan` (or another unused name). Choose **Public**.
3. Create the repository.
4. Open the new empty repository and choose **Add file → Upload files**.
5. Extract this ZIP on your computer first. Upload the four files listed above directly into the repository root. Do not upload the ZIP itself and do not put the files inside another folder.
6. Click **Commit changes**.
7. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch **main** and folder **/(root)**, then click **Save**.
9. Wait for the Pages deployment to finish. The website address should be `https://YOUR-GITHUB-USERNAME.github.io/samaq-al-maakan/`.

## Important
- This website is independent of EGCAN. No EGCAN URL or repository is needed for GitHub Pages to publish it.
- The website uses externally hosted Google Fonts and Unsplash sample photographs, so an internet connection is needed to load those resources.
- Replace the sample photographs with approved company photographs before presenting them as actual projects.
- The contact form currently prepares an email using the placeholder `info@samaqalmaakan.example`. Replace that address in `script.js` with the real company email before launch. The form opens the visitor's email application; it does not send directly to a website inbox.
- Add the approved company logo, phone/WhatsApp, address and verified company details before public launch.
